## What changed

- **A new shared page**, `00-governance/docs/plan-roles.md`, with the six terms, each role's part and five rules. It is listed in the package files.
- **07 Planning** (entry, contract, `prepare-plan` procedure, Codex template description): from preparing "bounded tasks" and returning "task proposals" to assembling epics and stories word for word, reporting back to their owners, and proposing the Product Backlog order and the Sprint Backlog. - **08 Low-Level Design** (entry, contract): splits each approved story into tasks, owns their content, answers issues from 09.
- **09 Build and Test** (entry, contract): updates task status, comments and signals blockers; never changes what a task is.
- **02, 03, 04, 05** (entries): which part of a story's content each owns, and that each reviews the assembled plan.
- **00, 01, 06, 10, 11, 12** (entries): one line pointing to the shared page.
- **Records:** 19 exact-hash receipts appended to the provider ledger (2330 to 2349 events) and the manifest refreshed.
